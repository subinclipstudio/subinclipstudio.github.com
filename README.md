# 클립 상품영상 스튜디오

상품 사진 5~10장과 확인된 상품 정보로 네이버 클립용 세로형 상품 홍보 영상(MP4), 표지 이미지, 300자 이내 게시글을 만드는 도구입니다.

흐름: **사진 업로드 → 상품 정보 확인 → 자동 생성 → 미리보기 → 수정 → 다운로드**

두 가지 버전이 있습니다.

| | 웹 버전 (바로 실행) | PC용 로컬 버전 |
|---|---|---|
| 실행 | https://subinclipstudio.github.io 접속 | 이 저장소를 내려받아 `run.bat` 실행 |
| 필요 환경 | PC·안드로이드의 최신 Chrome 또는 Edge | Windows + Python 3.11 이상 |
| 영상 만들기 | 브라우저 안에서(WebCodecs) H.264/AAC MP4 생성 | Python + FFmpeg로 생성 |
| 내레이션 | 지원 안 함 | Windows 한국어 음성(무료) 또는 CLOVA Voice(유료 키) |
| 사진 자동 분석 | 지원 안 함 | Claude API 키가 있으면 사용 |
| 저장 위치 | 이 브라우저(IndexedDB)에만. 서버로 보내지 않음 | PC의 `data/` 폴더 |

## 웹 버전

- 주소: **https://subinclipstudio.github.io**
- 설치 없이 열어서 바로 씁니다. 사진·상품 정보·영상은 그 브라우저 안에만 저장되고 어디에도 업로드되지 않습니다. 다른 기기나 다른 브라우저에서는 보이지 않고, 브라우저 데이터를 지우면 함께 지워집니다.
- 영상은 PC의 최신 Chrome·Edge에서 가장 안정적으로 만들어집니다. 브라우저가 H.264·AAC 인코딩을 지원하지 않으면(예: 일부 휴대폰·Safari) 화면에 그 사실을 표시하고 영상 생성을 막습니다. 사진·정보 입력과 게시글 작성은 가능합니다.
- 내레이션과 사진 자동 분석은 웹 버전에서 뺐습니다. 브라우저 음성은 파일로 녹음할 수 없고, 유료 API 키를 브라우저 코드에 넣으면 누구나 볼 수 있기 때문입니다.
- 웹 버전 파일: `index.html`, `web/` (영상 묶기에 MIT 라이선스 [mp4-muxer](https://github.com/Vanilagy/mp4-muxer) 5.2.1 사용, `web/vendor/`)

### GitHub Pages 설정 (저장소 관리자용)

1. 저장소 이름이 `subinclipstudio.github.io` 여야 https://subinclipstudio.github.io 로 열립니다. (Settings → General → Repository name)
2. Settings → Pages → Build and deployment 에서 Source: **Deploy from a branch**, Branch: **main / (root)** 를 선택합니다.
3. 1~2분 뒤 주소로 접속합니다.

# PC용 로컬 버전


## 1. 실행 방법 (로컬 버전)

필요한 것: Windows 10/11, Python 3.11 이상. FFmpeg는 따로 설치하지 않아도 됩니다(`imageio-ffmpeg` 패키지에 들어 있는 FFmpeg 7.1을 사용).

```bat
run.bat
```

처음 실행하면 `.venv` 가상환경을 만들고 패키지를 설치한 뒤 브라우저에서 http://127.0.0.1:8765 를 엽니다.

직접 실행하려면:

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8765
```

휴대폰에서 쓰려면 같은 와이파이에서 `--host 0.0.0.0` 으로 실행하고 `http://<PC IP>:8765` 로 접속합니다(인증 기능이 없으니 신뢰할 수 있는 네트워크에서만 쓰세요).

선택 기능(유료 API)을 쓰려면 `.env.example` 을 `.env` 로 복사해 키를 넣습니다. 키는 서버에서만 읽고 브라우저 코드에는 보내지 않습니다.

### 검증 스크립트

```bash
.venv\Scripts\python tests\e2e_test.py           # 1080×1920 최종 화질로 사진 5장·10장 검증
.venv\Scripts\python tests\e2e_test.py --quick   # 540×960으로 빠르게 검증
```

결과 영상·표지·확인용 프레임은 `tests/output/` 에 저장됩니다. 테스트 사진은 `tests/make_samples.py` 가 만든 가상 이미지입니다(실제 상품 아님).

## 2. 구현 완료 기능

| 영역 | 내용 |
|---|---|
| 상품 저장·불러오기 | 상품별로 `data/products/<id>/` 에 저장. 같은 상품을 선택하면 정보를 그대로 쓰고 ‘같은 상품 사진 모두 교체’로 사진만 바꿀 수 있음 |
| 구매 링크 보존 | 앞뒤 공백만 제거하고 쿼리 문자열(제휴 추적값 포함)은 바꾸지 않음. 게시글·복사 버튼 모두 원본 그대로 사용 |
| 사진 | 5~10장 업로드, 드래그(PC)·◀▶ 버튼(모바일)으로 순서 변경, 역할(제품 전체·세부 특징·사용 장면·포장·기타) 선택, 역할 기준 순서 제안. 사진은 EXIF 회전만 바로잡고 내용은 바꾸지 않음 |
| 영상 렌더링 | 9:16 · 1080×1920 · 30fps · MP4(H.264 High + AAC 192k), 15/25/35초. 원본 사진에 부드러운 확대·축소·좌우 이동과 장면 겹침 전환 적용. 생성형 영상 API 없이 Pillow + FFmpeg로 실제 파일 생성 |
| 장면 구성(25초 기준) | 0–3초 첫 문장 / 3–8초 브랜드·상품명 / 8–18초 특징·사용 상황 / 18–22초 핵심 정리 / 22–25초 마무리 화면. 다른 길이는 같은 비율로 조정하고 사진 수에 맞춰 장면 수·길이를 나눔(장면당 최소 1.2초) |
| 자막 | 한 화면 최대 두 줄, 자동 글자 크기(두 줄에 안 들어가면 생성 차단), 반투명 상자 + 외곽선으로 대비 확보. ‘맞춤’ 배치에서는 사진 영역과 자막 영역을 분리해 제품을 가리지 않음. 위·아래·좌우 안전 여백, 위치(아래/위/가운데)·미세 조정·크기 조절, 장면별 정지 미리보기에서 UI 겹침 영역 표시 |
| 브랜드 표시 | 도입부 제목 자막과 마무리 화면에 브랜드명·상품명 표시(마무리 화면은 상품 정보에서 자동으로 가져와 바꿀 수 없음) |
| 구매 안내 | 링크 위치(게시글·상품 태그·프로필·댓글·직접 입력·미정)를 고르게 함. 미정이면 ‘자세한 정보를 확인해 보세요’ 같은 중립 문구만 사용. 영상 속 주소 텍스트는 선택 사항이며 클릭되지 않는다고 안내 |
| 배경음악 | 밝고 경쾌한 / 차분하고 고급스러운 / 따뜻하고 편안한 / 음악 없음. 내장 3곡은 앱 코드(`app/music_gen.py`)가 직접 합성한 음원으로 외부 샘플을 쓰지 않으며 CC0 1.0으로 제공(`assets/music/library.json` 에 출처·라이선스·SHA-256 보관). 사용자 업로드는 출처·라이선스 입력과 상업적 이용·배포 허용 확인을 해야 사용 가능 |
| 내레이션 | 켜기/끄기. 확인된 정보로만 문장 생성. Windows 내장 한국어 음성(Heami)이 있으면 로컬에서 무료로 생성. 장면보다 길면 말하기 속도를 올리고, 그래도 길면 경고와 함께 끝을 줄임. 내레이션 구간에 배경음악 자동 낮춤, 음악·내레이션·전체 음량과 페이드인·아웃 조절. 음성 서비스가 없으면 내레이션 켜기를 막고 자막·음악만으로 생성 |
| 게시글 | 표시 문구·공백·줄바꿈·해시태그·링크를 모두 포함해 300자 이내로 생성. 넘으면 해시태그 → 부가 설명 순으로 줄이고, 표시 문구·브랜드/상품명·첫 특징·링크는 줄이지 않음. 필수 정보만으로 넘으면 링크를 빼고 따로 복사하라고 안내. 직접 수정 시 실시간 글자 수와 검사(표시 문구 원문 포함 여부, 링크 변경 여부, 제외 표현) |
| 표현 검사 | ‘최고·1위·최저가·완판·무조건·효과 보장·무첨가·인증·판매량’ 등 근거 확인이 필요한 표현은 생성 문구에 쓰지 않고, 입력·수정 문구에 있으면 경고. ‘제외할 표현’은 생성 차단 또는 선택 항목 삭제 |
| 결과 화면 | 영상 재생, 장면별 사진·자막·길이·움직임·내레이션 수정, 장면 순서·복제·삭제, 음악·내레이션 설정, 게시글 수정·글자 수·복사, 브랜드명·상품명·구매 링크 확인과 복사, MP4·표지 다운로드, 수정 반영해 다시 생성, 이전 결과 5개 보관 |
| 진행·오류 처리 | 8단계(입력 검증 → 사진 → 자막 → 내레이션 → 오디오 → 영상 → 표지 → 결과 검증) 진행 표시. 실패하면 실패 단계·원인·해결 방법·다시 시도 버튼 표시, 실패한 결과 파일은 삭제. 완료 전에 코덱·해상도·길이·전체 디코딩을 검사해 통과해야만 성공으로 표시 |
| 화면 | 한국어 UI, PC·휴대폰 반응형(375px 폭에서 가로 스크롤 없음), 밝은/어두운 테마 |

## 3. 외부 연결이 필요한 기능

화면 오른쪽 위 상태 표시(눌러서 자세히 보기)에 연결 여부가 그대로 나옵니다.

| 기능 | 서비스 | 비용 발생 시점 | 연결 방법 | 미연결 시 |
|---|---|---|---|---|
| 사진 역할 자동 추정, 사진 속 문자 후보 | Claude API (`claude-opus-5-5`) | 1단계 ‘사진 자동 분석’을 누를 때마다 1회 호출(사진 수만큼 이미지 입력). 누르기 전 확인 창 표시 | `.env` 에 `ANTHROPIC_API_KEY` | 역할을 직접 선택. 결과는 ‘자동 추정 n% — 확인 필요’로 표시되고 문자 후보는 눌러서 입력란에 넣은 뒤 저장해야 확정 |
| 고품질 내레이션 | NAVER CLOVA Voice (NCP) | 내레이션을 켜고 영상을 생성할 때 문장마다 호출 | `.env` 에 `NCP_CLOVA_CLIENT_ID`, `NCP_CLOVA_CLIENT_SECRET` | Windows 내장 음성 사용(무료). 둘 다 없으면 내레이션 없이 생성 |
| 네이버 클립 자동 게시 | — | — | 1차 범위 밖(별도 연동 과제) | 다운로드한 MP4·표지와 복사한 게시글·링크로 직접 게시 |

## 4. 검증 결과

`tests/e2e_test.py` 로 아래 항목을 사진 5장(25초·밝은 음악·내레이션 끔)과 사진 10장(15초·따뜻한 음악·Windows 내레이션 켬)에서 각각 확인했습니다. 결과는 `tests/e2e_full.log` 에 남아 있습니다.

- MP4 실제 다운로드(첨부 파일 헤더), H.264/AAC, 1080×1920, 30fps, 길이 일치, 전체 디코딩 오류 없음
- 사진 업로드·순서 변경 반영, 모든 사진이 장면에 사용됨, 프레임 추출로 사진·자막 표시 확인
- 브랜드명·상품명 정확, 구매 링크(쿼리 문자열 포함) 원본 보존 — 저장값과 게시글 모두
- 음악 선택·내레이션 켬/끔이 결과 파일에 반영(오디오 레벨 측정)
- 게시글 300자 이내, 표시 문구 원문 포함, 필수 정보만으로 넘을 때 링크 분리 안내
- 생성 문구에 근거 확인이 필요한 표현·제외 표현 없음
- 장면 자막·길이·사진·음악 수정 후 다시 생성 → 길이·음악 변경이 반영됨

## 5. 남은 제한 사항

- **네이버 공식 요건 미확인**: 1080×1920·30fps·H.264/AAC·15~35초는 앱 기본값이며 네이버 클립 공식 업로드 요건으로 확인한 값이 아닙니다. 게시 전에 최신 공식 안내를 확인하세요. 안전 여백 기본값(위 6%·아래 18%·좌우 6%)도 실제 앱 화면을 보고 조정이 필요할 수 있습니다.
- **경제적 이해관계 표시 문구**: 앱의 예시 문구는 참고용입니다. 최신 공식 안내(공정거래위원회 추천·보증 심사지침, 네이버 브랜드커넥트 안내)에 맞는 문구를 사용자가 확인해 넣어야 합니다.
- **글자 수 기준**: 유니코드 문자 단위(줄바꿈 1자)로 셉니다. 이모지 등은 네이버 쪽 계산과 다를 수 있으니 이모지를 넣으면 여유를 두세요.
- **사진 자동 분석**: API 키가 없으면 동작하지 않습니다. 키를 넣은 상태의 실제 호출은 이 환경에서 키가 없어 검증하지 못했습니다.
- **CLOVA Voice**: 키를 넣으면 호출하도록 구현했지만 이 환경에서 실제 호출은 검증하지 못했습니다. NCP의 API 주소가 바뀌었으면 `.env` 의 `CLOVA_TTS_URL` 로 바꿀 수 있습니다. ‘음성 들어보기’가 성공해야 연결됨으로 표시됩니다.
- **Windows 음성**: 로컬 음성이라 음질은 기본 수준이고, Windows가 아닌 환경에서는 쓸 수 없습니다.
- **렌더링 속도**: CPU로 한 장씩 합성합니다. 일반 PC에서 25초 최종 화질 기준 수십 초~1분 정도 걸리며, 작업은 한 번에 하나씩 처리합니다. 서버를 다시 시작하면 진행 중이던 작업 상태는 사라집니다(완료된 결과는 남음).
- **사용자 인증 없음**: 로컬 단일 사용자용입니다. 외부에 공개하려면 로그인·파일 접근 제어를 추가해야 합니다.
- **내장 음악**: 앱이 합성한 단순한 음악 3곡입니다. 더 높은 품질이 필요하면 라이선스를 확인한 음악을 업로드하세요.
